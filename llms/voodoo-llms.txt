# Voodoo

> Voodoo is a Paris-based mobile games and apps company (founded 2013, Alexandre Yazdi and Laurent
> Ritter) that develops and publishes free-to-play mobile titles, runs a partner publishing
> programme for external studios, operates the Voodoo ADN mobile ad network, and owns BeReal and
> Wizz. Voodoo publishes NO public API and NO machine-readable contract of any kind. Its
> developer-facing surface is a partner-gated dashboard plus first-party mobile ad SDKs.

This file was GENERATED by API Evangelist from the artifacts in this repository on 2026-09-04.
Voodoo does not serve an llms.txt: https://voodoo.io/llms.txt returned HTTP 404.

## What exists

- [Voodoo Publishing Platform API](https://voodoo.io/publishing): the HTTP backend behind the
  Publidash dashboard, at https://v2-publidash-api.voodoo.io. Real, but auth-gated: every route
  answers HTTP 401 anonymously. No OpenAPI, no GraphQL, no reference documentation.
- [Voodoo ADN iOS SDK](https://github.com/VoodooADN/ios-sdk-swiftpackage): mobile ad SDK,
  CocoaPods and Swift Package Manager, v3.17.1 released 2026-08-11.
- [Voodoo APPS ad tools for Android](https://github.com/VoodooTeam/APPS-ad-tools-android):
  io.voodoo.apps ad SDK, Maven at apps-sdk.voodoo-tech.io, last release 2025-04-28.

## What does not exist

- No OpenAPI, Swagger, GraphQL, AsyncAPI, gRPC or WSDL contract on any Voodoo host.
- No /.well-known document on any Voodoo host - no security.txt, no OIDC or OAuth metadata, no
  api-catalog, no apis.json, no agent card.
- No MCP server, hosted or local.
- No public developer portal, API reference, status page, trust center, or published rate limits.
- No published pricing: advertising is sold by sales contact, publishing is a revenue share.

## APIs

- [Voodoo Publishing Platform API](https://voodoo.io/publishing): partner-gated, undocumented,
  base https://v2-publidash-api.voodoo.io
